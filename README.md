# POVOコードカウンター Web版

POVOのプロモコードを登録し、複数コードを順番に使えるようにするWebアプリです。

## 使い方

1. メール本文をコード登録画面に貼り付ける
2. 複数のコードがある場合は、貼り付けた順番で登録される
3. 「コードを使う」を押すと、次のコードをコピーしてPOVOアプリを開く

Androidブラウザではプロモコード画面用のリンクを試します。端末やPOVOアプリが対応していない場合は、POVOアプリのホーム画面を開き、プロモコード画面へ進む案内を表示します。

## データについて

登録したコード、使用回数、使用履歴は、このアプリを開いた端末のブラウザ内に保存されます。
GitHubやこのWebアプリのサーバーへ登録コードを送信する機能はありません。
ブラウザのサイトデータを削除すると、登録内容も消えるため注意してください。

## 構成

このリポジトリはWeb版専用です。Androidアプリ本体は別のprivateリポジトリで管理します。
